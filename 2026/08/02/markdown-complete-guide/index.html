前言

Markdown 是一种用纯文本编写结构化文档的轻量级标记语言。掌握少量符号后，就可以编写 README、技术博客、学习笔记和项目文档。

这篇文章只保留最常用的内容。读完并跟着示例写一遍，就足以完成一篇清晰的 Markdown 文档。

一、先理解 Markdown

Markdown 使用符号表示文档结构，再由 GitHub、博客系统或编辑器将其渲染成网页：

Markdown 负责表达“这是什么内容”，字体、颜色和间距通常由网站主题决定。不同平台对扩展语法的支持可能不同，因此发布前应在目标平台预览一次。

Front Matter 必须位于文件最顶部，并由两行 --- 包围。字段中包含冒号等特殊字符时，给整个值加上引号更稳妥。

五、发布前检查

  • 标题层级是否连续，# 后是否有空格；
  • 段落之间是否留有空行；
  • 列表缩进和代码围栏是否完整；
  • 链接能否打开，图片路径和文件名大小写是否正确；
  • 是否已在实际发布平台预览；
  • 文中是否包含密码、密钥或本机绝对路径。

写在最后

日常写作真正需要记住的只有几类语法：标题、段落、强调、列表、链接、图片、代码块和表格。遇到复杂排版时，先考虑能否通过调整内容结构解决；Markdown 能清楚表达信息，就已经完成了它最重要的任务。
